### 1. Superstore Profitability Analysis (`Final.twb`)
**Course:** BAN 500, Fall 2025  
**Team:** Faith Elrod, Lauren Mitchek, Mason Capers  
**Tool:** Tableau Desktop

#### Business Problem
Superstore had a **12.46% profit margin** despite growing sales — a sign of operational inefficiency. The goal was to identify which product categories, subcategories, regions, and discount strategies were dragging profitability down and recommend actionable changes.

#### Dashboard Features
- **KPI Cards** for Total Profit, Profit Margin, and Total Sales — always visible
- **Regional profit comparison** highlighting the underperforming Central region
- **Category/subcategory breakdown** with green/red coloring for profit vs. loss
- **Discount vs. Profit line chart** showing the 20% discount threshold
- **$0 reference line** bolded to emphasize where discounts become harmful

#### Key Findings
- **Furniture** (especially Tables and Bookcases) generates losses that offset gains elsewhere
- **Discounts above 20%** result in negative profit — the Central region is most affected by this
- **Copiers, Phones, and Accessories** are the top revenue performers
- **Accessories, Paper, and Art** have the highest profit margins
- The Central region would perform competitively if Furniture losses were removed

#### Recommendations
1. Discontinue Tables; work toward breakeven on Bookcases
2. Cap all discounts at 20% company-wide
3. Replicate West region best practices in the Central region
4. Expand inventory of high-margin products: Copiers, Phones, Accessories

#### Design Principles Applied (*Storytelling with Data*)
- Minimal gridlines and no borders to reduce visual noise
- Intentional color use only (green/red for profit signals; highlight color for Central region)
- Descriptive chart titles stating the takeaway directly
- White space added to reduce cognitive load
- Horizontal/vertical bar charts for natural ranking readability

## How to View

1. Download [Tableau Public](https://public.tableau.com/en-us/s/download) (free) or open in Tableau Desktop
2. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/tableau-dashboards.git
   ```
3. Open the `.twb` file in Tableau

> **Note:** `.twb` files reference external data sources. If the data connection is unavailable, Tableau will prompt you to reconnect. The Superstore dataset is built into Tableau and should connect automatically.
